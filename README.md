# 🛵 OLA Driver Churn Analysis

An end-to-end **Exploratory Data Analysis and Machine Learning** project analyzing driver churn to identify key factors influencing employee retention and attrition.

## 🔍 What I Analyzed

- 📊 Driver demographics and performance
- 💼 Grade and joining designation
- ⭐ Quarterly ratings and rating improvements
- 💰 Salary increments and churn behavior
- 🔗 Feature relationships with churn
- 🤖 Churn prediction and model evaluation

## 💡 Key Insights

- **67.9% of drivers had churned**, indicating a significant retention challenge.
- Drivers with **higher grades** showed lower churn tendencies.
- Drivers whose **quarterly ratings improved were less likely to leave**.
- Drivers without **salary increases showed higher churn rates**. :contentReference[oaicite:1]{index=1}

## 🎯 Business Impact

The analysis identifies key retention drivers and provides a foundation for **targeted employee engagement, compensation strategies, performance management, and churn reduction**.
